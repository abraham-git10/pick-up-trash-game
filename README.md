Goal: Clear all cells of trash to win the game

### **Game Controls & Rules**

1. **Start the Game**: Run the application to launch the game window.
2. **Key**:
   - **Black / Filled Squares**: Trash that needs to be picked up.
   - **White / Empty Squares**: Cleaned cells.
3. **Pick Up Trash Function**:
   - Click on any black cell (trash cell).
   - The game will automatically sweep and clear all connected adjacent trash pieces (up, down, left, right)
4. **Win the Game**:
   - Continue clicking trash spots until no black squares remain.
   - Once the board is entirely clear, the screen will reveal the victory message
